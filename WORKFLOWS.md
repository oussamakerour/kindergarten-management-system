## 1. دورة حياة طلب النشاط والتحصيل (Activity Request & Collection Workflow)

### المراحل الرئيسية:

```
┌─────────────────────────────────────────────────────────────────────┐
│                    دورة حياة طلب النشاط                             │
└─────────────────────────────────────────────────────────────────────┘

    ┌──────────────────┐
    │  المعلمة/المربية  │
    │  تنشئ طلب نشاط    │
    └────────┬─────────┘
             │
             ▼
    ┌──────────────────────────────────────────┐
    │ 1️⃣ مرحلة التقديم (Submission Phase)      │
    │                                          │
    │ ✓ تعبئة نموذج النشاط:                   │
    │   - الاسم والوصف                        │
    │   - النوع والتاريخ                      │
    │   - الموقع والتكلفة                     │
    │   - الأقسام المستهدفة                  │
    │   - الحد الأقصى للمشاركين               │
    │                                          │
    │ ✓ الحالة: قيد الانتظار (Pending)        │
    │ ✓ المسؤول: المعلمة                      │
    └────────┬─────────────────────────────────┘
             │
             ▼
    ┌──────────────────────────────────────────┐
    │ 2️⃣ مرحلة الموافقة (Approval Phase)      │
    │                                          │
    │ ✓ المسير العام يراجع الطلب              │
    │ ✓ التحقق من:                           │
    │   - صحة المعلومات                       │
    │   - الميزانية المتاحة                   │
    │   - توفر الموارد                        │
    │   - توافق المواعيد                      │
    │                                          │
    │ ✓ القرار: الموافقة أو الرفض             │
    │                                          │
    │ الحالات الممكنة:                        │
    │ ├─ ✅ موافق (Approved)                  │
    │ └─ ❌ مرفوض (Rejected)                  │
    └────────┬─────────────────────────────────┘
             │
    ┌────────┴──────────────┬──────────────────┐
    │                       │                  │
    ▼                       ▼                  ▼
┌──────────────┐    ┌──────────────────┐  ┌──────────────┐
│ ✅ موافق    │    │ ❌ مرفوض        │  │ ⏳ معلق      │
│              │    │                  │  │ (يحتاج تعديل)│
└──────┬───────┘    └──────┬───────────┘  └──────┬───────┘
       │                   │                     │
       ▼                   ▼                     ▼
  المرحلة 3️⃣        إخطار المعلمة      طلب تعديل من المعلمة
```

### المرحلة 3️⃣: إدارة المشاركين والتحصيل (Enrollment & Collection)

```
    ┌───────────────────────────────────────────────────┐
    │ 3️⃣ مرحلة إدارة المشاركين (Enrollment Phase)     │
    │                                                   │
    │ ✓ المعلمة تضيف الأطفال المشاركين:              │
    │   - اختيار الأطفال من القوائم                   │
    │   - تحديد حالة المشاركة (مؤكد/معلق)             │
    │                                                   │
    │ ✓ النظام يسجل:                                 │
    │   - عدد المشاركين                              │
    │   - التاريخ والوقت                             │
    │   - حالة المشاركة                              │
    │                                                   │
    │ ✓ إرسال إشعارات للأولياء بتفاصيل النشاط        │
    │   - الاسم والتاريخ                             │
    │   - الموقع والتكلفة (إن وجدت)                 │
    │   - آخر موعد للتسجيل                           │
    └────────┬────────────────────────────────────────┘
             │
             ▼
    ┌───────────────────────────────────────────────────┐
    │ 4️⃣ مرحلة التحصيل (Collection Phase)             │
    │                                                   │
    │ إذا كان النشاط مدفوعاً:                         │
    │                                                   │
    │ ✓ إنشاء فاتورة مالية تلقائية:                  │
    │   - لكل طفل مشارك                              │
    │   - تحمل رقم الفاتورة الفريد                   │
    │   - تاريخ الاستحقاق (قبل النشاط)              │
    │                                                   │
    │ ✓ المعلمة تحصل الدفعات:                        │
    │   - تحديث حالة الدفع (مدفوع/معلق)             │
    │   - طباعة الإيصالات                            │
    │   - تسجيل طريقة الدفع                          │
    │                                                   │
    │ ✓ النظام يتحقق من:                            │
    │   - عدد المتسددين                              │
    │   - المبلغ المجمع                              │
    │   - المتأخرين                                 │
    │                                                   │
    │ حالات الدفع:                                   │
    │ ├─ ✅ مدفوع بالكامل (Fully Paid)             │
    │ ├─ ⏳ دفعة جزئية (Partial)                    │
    │ └─ ❌ معلق (Pending)                          │
    └────────┬────────────────────────────────────────┘
             │
             ▼
    ┌───────────────────────────────────────────────────┐
    │ 5️⃣ مرحلة التنفيذ (Execution Phase)              │
    │                                                   │
    │ ✓ في تاريخ النشاط:                             │
    │   - تسجيل الأطفال الحاضرين فعلياً               │
    │   - توثيق الصور/الفيديو (اختياري)             │
    │   - تقييم النشاط                               │
    │                                                   │
    │ ✓ بعد النشاط:                                  │
    │   - إرسال تقرير النشاط للأولياء                │
    │   - توثيق النتائج والفوائد                     │
    │   - طلب تقييم النشاط من الأولياء               │
    └────────┬────────────────────────────────────────┘
             │
             ▼
    ┌───────────────────────────────────────────────────┐
    │ 6️⃣ مرحلة الإغلاق (Closure Phase)               │
    │                                                   │
    │ ✓ التقرير المالي النهائي:                      │
    │   - إجمالي الإيرادات                            │
    │   - عدد المشاركين الفعلي                        │
    │   - المتأخرين عن الدفع                          │
    │                                                   │
    │ ✓ تحديث السجلات:                               │
    │   - حالة النشاط: مكتمل (Completed)             │
    │   - إرشفة البيانات                             │
    │                                                   │
    │ ✓ الحفظ في التقارير المالية السنوية            │
    └───────────────────────────────────────────────────┘
```

## 2. دورة تسجيل الحضور والرواتب (Attendance & Payroll Workflow)

### المرحلة 1️⃣: تسجيل الحضور اليومي (Daily Attendance)

```
┌─────────────────────────────────────────────────────────────────────┐
│                    دورة تسجيل الحضور والرواتب                       │
└─────────────────────────────────────────────────────────────────────┘

الوقت: 8:00 صباحاً (بداية اليوم الدراسي)

    ┌──────────────────────────────────────┐
    │ المعلمة تسجل الحضور في تطبيق النظام │
    │                                      │
    │ ✓ تحديد القسم                        │
    │ ✓ تحديد التاريخ                      │
    │ ✓ تسجيل حالة كل طفل:                │
    │   • ✅ حاضر                         │
    │   • ❌ غائب                         │
    │   • ⏰ متأخر                         │
    │   • ⚠️ معذور                        │
    │   • 🏥 في إجازة/مرض                │
    │                                      │
    │ ✓ إضافة ملاحظات (اختياري)           │
    └────────┬─────────────────────────────┘
             │
             ▼
    ┌──────────────────────────────────────┐
    │ النظام يحفظ البيانات تلقائياً         │
    │                                      │
    │ ✓ يسجل:                             │
    │   - اسم الطفل                       │
    │   - الحالة                          │
    │   - وقت التسجيل                     │
    │   - من قام بالتسجيل                 │
    │                                      │
    │ ✓ إرسال إشعار فوري للأولياء:        │
    │   "تم تسجيل حضور أحمد"              │
    └────────┬─────────────────────────────┘
             │
             ▼
    ┌──────────────────────────────────────┐
    │ النظام ينشئ إحصائيات يومية           │
    │                                      │
    │ ✓ عرض ملخص الحضور:                  │
    │   - حاضرون: 40 طفل                 │
    │   - غائبون: 4 أطفال                │
    │   - متأخرون: 1 طفل                 │
    │   - معذورون: 2 طفل                 │
    │   - الإجمالي: 47 طفل               │
    │                                      │
    │ ✓ تنبيهات المعلمة:                  │
    │   - عدد الغائبين الجدد              │
    │   - التغيب المتكرر لطفل معين        │
    └────────┬─────────────────────────────┘
             │
             ▼
    ┌──────────────────────────────────────┐
    │ (اختياري) حضور المعلمات والموظفين  │
    │                                      │
    │ ✓ المعلمة تسجل حضورها                │
    │ ✓ الموظفين يسجلون حضورهم             │
    │ ✓ يتم ربطه بنظام الرواتب              │
    └────────┬─────────────────────────────┘
```

### المرحلة 2️⃣: تحليل البيانات الشهرية (Monthly Analysis)

```
    ┌─────────────────────────────────────────────────────┐
    │ في نهاية الشهر: معالجة بيانات الحضور الشهرية      │
    │                                                     │
    │ ✓ النظام يحسب:                                     │
    │   - أيام الحضور لكل طفل                           │
    │   - نسبة الحضور (%)                              │
    │   - عدد أيام الغياب                               │
    │   - عدد أيام التأخر                               │
    │                                                     │
    │ ✓ تقارير شهرية:                                   │
    │   - تقرير الحضور الشامل                           │
    │   - الأطفال الأكثر غياباً                         │
    │   - الأطفال منتظمو الحضور                         │
    │                                                     │
    │ ✓ الإشعارات:                                      │
    │   - تنبيه الأولياء بالغياب المتكرر               │
    │   - تحذير من توقف البرنامج (إذا تجاوز الغياب)    │
    └────────┬─────────────────────────────────────────┘
             │
             ▼
    ┌─────────────────────────────────────────────────────┐
    │ المرحلة 3️⃣: حساب رواتب المعلمات والموظفين        │
    │                                                     │
    │ العناصر المحسوبة:                                 │
    │                                                     │
    │ 1️⃣ الراتب الأساسي:                               │
    │    - الراتب المقرر لكل معلمة                      │
    │    - مثال: $800/شهر                              │
    │                                                     │
    │ 2️⃣ بدل الحضور:                                   │
    │    - عدد أيام العمل المتوقعة: 22 يوم            │
    │    - عدد أيام الحضور الفعلي: 21 يوم             │
    │    - نسبة الحضور: 21/22 = 95.45%               │
    │    - الراتب بعد الحضور: $800 × 95.45% = $763.60 │
    │                                                     │
    │ 3️⃣ البدلات والمكافآت:                            │
    │    - بدل النقل: $50                              │
    │    - بدل الوجبة: $30                             │
    │    - مكافأة الأداء: $100                         │
    │    - مكافأة التميز: $50                          │
    │    - الإجمالي: $230                              │
    │                                                     │
    │ 4️⃣ الخصومات:                                     │
    │    - الضرائب: $76.36 (10%)                      │
    │    - التأمينات: $50                              │
    │    - قرض سابق: $25                              │
    │    - إجازة بدون راتب: -$0                        │
    │    - الإجمالي: $151.36                           │
    │                                                     │
    │ 5️⃣ الراتب النهائي:                               │
    │    = الأساسي + البدلات - الخصومات                │
    │    = $763.60 + $230 - $151.36                   │
    │    = $842.24                                     │
    └────────┬─────────────────────────────────────────┘
             │
             ▼
    ┌─────────────────────────────────────────────────────┐
    │ المرحلة 4️⃣: مراجعة الرواتب (Salary Review)       │
    │                                                     │
    │ ✓ المسير العام يراجع:                            │
    │   - حسابات الرواتب                               │
    │   - الخصومات والبدلات                            │
    │   - أي استثناءات أو حالات خاصة                  │
    │                                                     │
    │ ✓ الحالات المحتملة:                             │
    │   - ✅ موافق                                    │
    │   - ❌ بحاجة تعديل                              │
    │   - ⏳ معلق (ينتظر توضيح)                      │
    └────────┬─────────────────────────────────────────┘
             │
             ▼
    ┌─────────────────────────────────────────────────────┐
    │ المرحلة 5️⃣: تحويل الرواتب (Salary Transfer)      │
    │                                                     │
    │ ✓ طريقة الدفع المختارة:                          │
    │   - 💳 تحويل بنكي (الأفضل)                      │
    │   - 💰 نقد (يدوي)                               │
    │   - ✓ شيك                                       │
    │                                                     │
    │ ✓ النظام يسجل:                                   │
    │   - تاريخ التحويل                               │
    │   - المبلغ المحول                               │
    │   - رقم التحويل/الإيصال                         │
    │   - حالة الدفع: مدفوع ✅                        │
    │                                                     │
    │ ✓ إرسال إشعار للمعلمة:                          │
    │   "تم تحويل راتبك بنجاح: $842.24"              │
    └────────┬─────────────────────────────────────────┘
             │
             ▼
    ┌─────────────────────────────────────────────────────┐
    │ المرحلة 6️⃣: إنشاء التقارير (Report Generation)  │
    │                                                     │
    │ ✓ تقارير الرواتب:                               │
    │   - كشف رواتب شامل لجميع الموظفين               │
    │   - تقرير الحضور/الغياب                          │
    │   - تقرير المستحقات المالية                      │
    │                                                     │
    │ ✓ الملفات المُنتجة:                             │
    │   - PDF: جاهز للطباعة                           │
    │   - Excel: للتحليل الإضافي                      │
    │   - CSV: للأرشفة                                │
    │                                                     │
    │ ✓ الحفظ:                                        │
    │   - في النظام تاريخياً                           │
    │   - في الملفات المالية                          │
    └────────┬─────────────────────────────────────────┘
             │
             ▼
    ┌─────────────────────────────────────────────────────┐
    │ النتيجة النهائية:                                 │
    │                                                     │
    │ ✅ رواتب المعلمات والموظفين محسوبة بدقة           │
    │ ✅ جميع البيانات موثقة ومحفوظة                    │
    │ ✅ تقارير شاملة متاحة للمسير                       │
    │ ✅ إشعارات موثوقة للجميع                          │
    │ ✅ سجل تاريخي كامل للأرشفة                       │
    └─────────────────────────────────────────────────────┘
```

## 3. دورة جمع الاشتراكات المنتظمة (Regular Subscription Collection)

```
┌─────────────────────────────────────────────────────────────────────┐
│              دورة جمع الاشتراكات الشهرية/اليومية                    │
└─────────────────────────────────────────────────────────────────────┘

    ┌──────────────────────────────────────┐
    │ المرحلة 1️⃣: إنشاء الاشتراك          │
    │                                      │
    │ عند التحاق طفل جديد:                 │
    │ ✓ تسجيل بيانات الطفل                │
    │ ✓ اختيار نوع الاشتراك:              │
    │   - يومي (Daily): $10/يوم            │
    │   - شهري (Monthly): $200/شهر        │
    │   - ربع سنوي: $550 (مع خصم)         │
    │   - سنوي: $2,000 (مع خصم)           │
    │ ✓ تحديد تاريخ البداية                │
    │ ✓ حفظ الاشتراك في النظام             │
    └────────┬─────────────────────────────┘
             │
             ▼
    ┌──────────────────────────────────────┐
    │ المرحلة 2️⃣: فترة الاستحقاق         │
    │                                      │
    │ النظام يحسب:                        │
    │ ✓ تاريخ الاستحقاق                   │
    │   - إذا شهري: آخر يوم في الشهر       │
    │   - إذا يومي: كل يوم عمل             │
    │                                      │
    │ ✓ قيمة الاشتراك المستحق             │
    │   - مبلغ الاشتراك                   │
    │   - الخصومات المطبقة                │
    │   - المبلغ النهائي                  │
    │                                      │
    │ ✓ فترة السماح: عادة 5 أيام بعد      │
    │   تاريخ الاستحقاق                   │
    └────────┬─────────────────────────────┘
             │
             ▼
    ┌──────────────────────────────────────┐
    │ المرحلة 3️⃣: التذكيرات               │
    │                                      │
    │ إرسال إشعارات للأولياء:            │
    │                                      │
    │ 1️⃣ قبل الاستحقاق بـ 3 أيام:        │
    │    "تذكر: الاشتراك المستحق: $200"   │
    │                                      │
    │ 2️⃣ في يوم الاستحقاق:              │
    │    "الاشتراك المستحق اليوم: $200"   │
    │                                      │
    │ 3️⃣ بعد الاستحقاق بـ 5 أيام:        │
    │    "تذكر نهائي: الرصيد المستحق"     │
    │                                      │
    │ 4️⃣ الرسالة الطبية (قبل التوقف):   │
    │    "سيتم إيقاف الطفل عن البرنامج"  │
    └────────┬─────────────────────────────┘
             │
             ▼
    ┌──────────────────────────────────────┐
    │ المرحلة 4️⃣: جمع الدفعات            │
    │                                      │
    │ المعلمة تحصل الدفعات:              │
    │ ✓ من الأولياء مباشرة                │
    │ ✓ تسجيل كل دفعة في النظام            │
    │ ✓ تحديد طريقة الدفع                 │
    │ ✓ طباعة إيصال فوري                  │
    │                                      │
    │ الحالات المحتملة:                  │
    │ ├─ ✅ دفع كامل                     │
    │ ├─ ⏳ دفع جزئي                    │
    │ ├─ ❌ عدم الدفع                    │
    │ └─ 💳 وعد بدفع لاحق                │
    └────────┬─────────────────────────────┘
             │
             ▼
    ┌──────────────────────────────────────┐
    │ المرحلة 5️⃣: تحديث الحالة            │
    │                                      │
    │ النظام يحدّث:                      │
    │ ✓ حالة الاشتراك (مدفوع/معلق)       │
    │ ✓ الرصيد المتبقي                   │
    │ ✓ تاريخ آخر دفعة                    │
    │ ✓ تاريخ الاستحقاق التالي           │
    │                                      │
    │ إرسال إشعار تأكيد للأولياء:         │
    │ "تم استلام دفعتك: $200 - شكراً"     │
    └────────┬─────────────────────────────┘
             │
             ▼
    ┌──────────────────────────────────────┐
    │ المرحلة 6️⃣: التقارير               │
    │                                      │
    │ يومياً:                            │
    │ ✓ تقرير تحصيل يومي                 │
    │   - إجمالي المجموع                │
    │   - عدد الدفعات                    │
    │   - المتأخرين                      │
    │                                      │
    │ شهرياً:                            │
    │ ✓ تقرير الدفعات الشامل              │
    │ ✓ تقرير الديون المستحقة            │
    │ ✓ تقرير النسب المئوية              │
    │                                      │
    │ سنوياً:                            │
    │ ✓ التقرير المالي الشامل            │
    └────────┬─────────────────────────────┘
             │
             ▼
    ┌──────────────────────────────────────┐
    │ النتيجة النهائية:                   │
    │                                      │
    │ ✅ متابعة منتظمة للدفعات            │
    │ ✅ تقليل الديون المستحقة            │
    │ ✅ تحسين التدفق النقدي              │
```

## 5. متطلبات النظام والقيود (System Requirements & Constraints)

### القيود والتحقق من الصحة (Validations)

```
1️⃣ تسجيل الأطفال:
   ✓ يجب أن يكون عمر الطفل بين 1-6 سنوات
   ✓ لا يمكن تسجيل طفل في قسم غير مناسب لعمره
   ✓ لا يمكن تجاوز سعة الفصل

2️⃣ الاشتراكات:
   ✓ المبلغ يجب أن يكون أكبر من صفر
   ✓ تاريخ البداية يجب أن يكون قبل تاريخ النهاية
   ✓ لا يمكن إنشاء اشتراكين متزامنين للطفل الواحد

3️⃣ الدفعات:
   ✓ المبلغ المدفوع لا يزيد عن المبلغ المستحق
   ✓ تاريخ الدفع لا يزيد عن تاريخ اليوم
   ✓ رقم الإيصال فريد لكل دفعة

4️⃣ الأنشطة:
   ✓ لا يمكن الموافقة على نشاط بدون وصف كامل
   ✓ تاريخ النشاط يجب أن يكون مستقبلياً
   ✓ لا يمكن تعديل نشاط بعد الموافقة عليه

5️⃣ الرواتب:
   ✓ الراتب الأساسي يجب أن يكون موجباً
   ✓ نسبة الحضور بين 0-100%
   ✓ الراتب النهائي = (الأساسي × نسبة الحضور) + البدلات - الخصومات

6️⃣ الحضور:
   ✓ لا يمكن تسجيل حضور مستقبلي
   ✓ لا يمكن تسجيل حضوري لنفس الشخص في نفس اليوم
   ✓ وقت الحضور يجب أن يكون قبل وقت المغادرة
```

## 6. الإجراءات التصحيحية والاستثناءات (Exception Handling)

### الحالات الخاصة:

```
⚠️ إذا تأخر الدفع:
   1️⃣ إرسال تنبيه أول
   2️⃣ بعد 3 أيام: إرسال تنبيه ثاني مع تحذير
   3️⃣ بعد أسبوع: اتصال هاتفي من المعلمة
   4️⃣ بعد أسبوعين: تحذير من إيقاف الطفل
   5️⃣ بعد شهر: إيقاف الطفل عن البرنامج مؤقتاً
   6️⃣ بعد شهرين: إيقاف الطفل من البرنامج نهائياً

⚠️ إذا تكرر الغياب:
   1️⃣ بعد 3 أيام غياب متتالي: إخطار الأولياء
   2️⃣ بعد أسبوع: اتصال هاتفي للتحقق
   3️⃣ بعد أسبوعين: اجتماع مع الإدارة والأولياء
   4️⃣ إذا تجاوز 30%: قد يتم حرمان الطفل من الأنشطة

⚠️ إذا تأخرت المعلمة:
   1️⃣ أول 2 مرات: تنبيه شفهي
   2️⃣ المرة الثالثة: خصم 50% من البدل
   3️⃣ المرة الرابعة: خصم 100% من البدل + تنبيه رسمي
   4️⃣ المرات المتكررة: إجراءات تأديبية

⚠️ إذا لم توافق الميزانية:
   1️⃣ النشاط المكلف: طلب موافقة إضافية من مجلس الإدارة
   2️⃣ نشاط مدفوع: التأكد من رضا الأولياء عن التكلفة
   3️⃣ نشاط مجاني بميزانية: البحث عن تمويل بديل
```
